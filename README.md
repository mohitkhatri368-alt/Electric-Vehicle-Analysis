# 🚗 Electric Vehicle Market Analysis

## 📌 Project Overview

Analyzed Electric Vehicle registration and renewable energy datasets using Python and Power BI to identify adoption trends and market growth.

---

## 🎯 Business Problem

Understanding EV adoption trends helps governments and businesses make informed decisions regarding sustainable transportation.

---

## 🛠️ Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI

---

## 📊 Dashboard Features

- State-wise EV Registrations
- EV Growth Trends
- Energy Source Analysis
- Interactive Maps
- KPI Cards

---

## 📈 Key Insights

- EV registrations increased steadily.
- Some states lead in EV adoption.
- Renewable energy growth supports EV expansion.
